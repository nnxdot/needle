Make Needle yours.

A theme is one small text file. It starts from one of Needle's looks and changes the colors you choose. Make one in the app with color pickers, or write the file by hand.

Make a theme

  1. Open Settings, then Appearance.
  2. Choose the look you want to start from, then press Make a copy.
  3. Give it a name. Change any color with its color picker. Needle shows each change straight away and saves as you go.
  4. Press Done. Your theme stays in the list of looks, next to Night, Midnight, and Day.

A color you leave alone follows the look you started from and the colors you set. For example, set only Page, and the lines and cards follow it. Press Reset beside a color to let it follow again.

The theme file

Themes are .toml files in Needle's themes folder. Press Open themes folder in Settings › Appearance to find it. Needle sees a new or changed file within two seconds, so you can edit one in any text editor and watch the change.

name = "Sakura"
author = "you"
base = "light"
music_colors = true

[colors]
page = "#fff5f7"
sidebar = "#fbe9ee"
accent = "#c2185b"
text = "#3a2230"

[extras]
grain = 0.15
font = "fraunces"
KeyNeededWhat it is
nameNoThe name people see. The default is the file name.
authorNoYour name.
baseNoThe look to start from: "dark" (Night), "midnight", or "light" (Day). The default is "dark".
music_colorsNoWith Colors from the music on, the cover that is playing may tint the colors this theme leaves out. The default is true. Set false to keep the theme's colors always.
[colors]NoThe colors to change, as "#rrggbb". See Colors.
[extras]NoFilm grain and a title font, applied when someone chooses the theme. See Extras.

A dark page makes a dark theme, and a light one a light theme, whatever the base.

Colors

KeyWhat it paints
sidebarThe sidebar, the title bar, and the player at the bottom.
pageThe sheet the songs and pages sit on.
cardHovered rows, search fields, and cards.
card_hoverCards and buttons under the pointer.
borderBorders around fields and cards.
border_softQuiet dividers between rows and sections.
textTitles and most text.
text_mutedArtists, albums, and descriptions.
text_faintSmall print, times, and hints.
accentButtons, switches, the playing song, and links.
accent_textLabels on accent buttons.
dangerErrors and delete buttons.
successThings that went well.
glowThe soft light behind covers and page headers.

Extras

KeyWhat it is
grainFilm grain over the window, from 0 (off) to 1.
fontThe font for page titles and big names: "system" (Segoe UI), "bahnschrift", or "fraunces".

Extras are set when someone chooses the theme. They can still change them afterwards in Settings.

Readable text

Needle keeps every text color readable on the sidebar, the page, and cards (a contrast of at least 4.5 to 1, the WCAG AA level). When a color you chose is too close to its background, Needle makes it just lighter or darker enough, and the editor says which colors moved. If no text color can read on both the sidebar and the page, Needle moves the sidebar toward the page.

Themes change colors, the title font, and grain only. They cannot change the layout, so a theme cannot break Needle.

Sharing

  • Export… in Settings › Appearance saves the theme in use as a file you can send to anyone.
  • To add a theme, drop its file on the Needle window, or press Add a theme…. Needle copies it into the themes folder and switches to it.
  • If the name is taken, Needle adds a number to the file name. Nothing is overwritten.

Themes in plugins

A plugin can bring themes: put .toml theme files in a themes folder inside the plugin's folder. They show in the list of looks while the plugin is on, marked with the plugin's name. They cannot be changed in place; press Make a copy to make your own version. A plugin needs no permission to bring themes.

plugins/
  pastels/
    plugin.toml
    themes/
      mint.toml
      lilac.toml

A plugin that only brings themes needs no script: a plugin.toml and the themes folder are enough.

A plugin can also make themes: with the "files" permission, write_file("themes/name.toml", text) adds one, and Needle shows it within two seconds. With opens = ["json"] and on_file_dropped, or pick_file, it can turn another app's theme file into a Needle theme.

When something goes wrong

My theme does not show
Check that the file ends in .toml and is in the themes folder. A file Needle cannot read shows under the looks with what is wrong, such as "pink" is not a color like "#e75480".
A color looks different from the one I chose
Needle moved it so text stays readable. The editor marks it with Moved a little so text stays readable. Choose a lighter or darker background, or a text color further from it.
The colors change with each song
The theme allows colors from the music, and Colors from the music is on. Set every color you care about, set music_colors = false, or turn the switch off in the editor.
A plugin's theme is gone
Plugin themes show only while the plugin is on. If the theme you use goes away, Needle uses Night until you choose another look.
