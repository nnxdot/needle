Plugins

Teach Needle new tricks.

A plugin is a small script in its own folder. It can react to what you play, add commands to menus, and use your library, but only in the ways it asks for. Nothing runs until you turn it on.

Your first plugin

Plugins are written in Rhai, a small scripting language that looks like JavaScript or Rust. You need a text editor and nothing else.

  1. In Needle, open Settings, then Plugins, and press Open plugins folder.
  2. Make a new folder in it, for example hello.
  3. In that folder, make a file named plugin.toml: 
    id = "hello"
name = "Hello"
version = "1.0.0"
description = "Says the name of each song as it starts."
author = "you"
  4. Next to it, make a file named main.rhai: 
    fn on_track_start(track) {
    notify(`Now playing ${track.title} by ${track.artist}`);
}
  5. Back in Needle, press Reload. Your plugin shows in the list. Turn it on, then play a song.

Every time you change a file, press Reload to load it again. To see finished plugins, press Add example plugins. Needle then copies four examples into the folder (see Examples).

plugin.toml

This file tells Needle what the plugin is and what it may do.

KeyNeededWhat it is
idYesA short name that never changes. Use only letters, digits, - and _. Needle keeps the plugin's on/off state and its settings under this name.
nameYesThe name people see.
versionNoYour version, such as "1.0.0".
descriptionNoOne or two sentences about what it does.
authorNoYour name.
entryNoThe script file. The default is "main.rhai". It must be inside the plugin folder.
permissionsNoA list of what the plugin may do. The default is none.

Permissions

Ask only for what you use. Needle shows the list before someone turns the plugin on. Turning it on allows everything on the list.

PermissionAllows
"library.read"Searching songs and reading listening history.
"library.write"Changing ratings and saving playlists.
"playback"Playing, pausing, skipping, and adding to the queue.
"network"Web requests.
"files"Reading and writing files inside the plugin's own folder.
 
permissions = ["library.read", "playback"]

Events

Define any of these functions, and Needle calls them at the right time. You can leave out the ones you do not need.

FunctionCalled when
on_load()The plugin is turned on, and when Needle starts or reloads plugins.
on_track_start(track)A song starts. track is a song.
on_listen(listen)Needle records a listen in your history. listen is a listen.
on_pause()Playback pauses.
on_resume()Playback starts again after a pause.

Code outside functions runs once, when the plugin loads. Rhai functions cannot see variables made outside them, so to remember something between calls, use set_setting and setting.

Commands

A plugin can add commands that people choose. commands() returns a list of them. run(command, ids) is called when one is chosen.

fn commands() {
    [
        #{ id: "five", title: "Rate five stars", scope: "track" },
        #{ id: "tidy", title: "Tidy my queue", scope: "global" },
    ]
}

fn run(command, ids) {
    if command == "five" {
        for id in ids { set_rating(id, 5); }
        notify(`Rated ${ids.len()} songs.`);
    }
}
  • "track" commands show in the menu of selected songs, under Plugins. ids holds the selected songs' ids.
  • "global" commands show in the command palette. ids is empty.
  • A plugin can have at most 32 commands. Needle asks for the list when the plugin loads, so press Reload after you change it.

Functions

These are the functions your script can call. A function that needs a permission fails with a clear message if the plugin did not ask for that permission.

Always allowed

notify(text)
Shows a short message in Needle, with your plugin's name in front.
log(text)
Writes a line to Needle's error output. Needle's window does not show it, so use notify while you test.
now()
The current time, in seconds since 1 January 1970 (UTC).
now_playing()
The song playing now, or () if none.
setting(key)
A value this plugin saved earlier, or () if there is none.
set_setting(key, value)
Saves a value for this plugin. It is kept when Needle closes. Each plugin has its own settings.
parse_json(text)
Turns JSON text into Rhai maps and arrays.

library.read

library_search(rule)
Songs that match a search or a rule, the same as the search box in Needle. For example: "rating >= 4 and year < 2000", or "played(7d) order by play_count desc limit 25". Gives at most 10,000 songs. An empty rule gives all songs.
recent_listens(count)
Your most recent listens, newest first, from 1 to 1,000.

library.write

set_rating(id, stars)
Sets a song's rating, from 0 (none) to 5.
save_playlist(name, ids)
Saves a playlist with these songs. If your plugin saves a playlist with the same name again, Needle updates it and does not make a second one.

playback

play(ids)
Plays these songs now.
play_next(ids)
Puts these songs next in the queue.
enqueue(ids)
Adds these songs to the end of the queue.
toggle_playback()
Pauses, or plays again.
next_track(), previous_track()
Skips forward or back.

network

http_get(url)
Fetches a web address and gives its text.
http_post_json(url, value)
Sends value as JSON and gives the reply's text.

A request stops after 15 seconds. A reply is cut at 1 MB. A reply that is not a success fails with the server's status.

files

read_file(name)
Reads a text file in the plugin's folder.
write_file(name, text)
Writes a text file in the plugin's folder, and replaces what was there.

Use a plain file name, such as "now-playing.txt". Folders, .., and full paths are refused, so a plugin cannot touch files outside its folder.

Songs and listens

Songs and listens are Rhai maps. Read a field with a dot, such as track.title.

Song

id
Needle's id for the song. Use it with the functions above.
title, artist, album, album_artist, genre
Text. Empty when the file has none.
year
A number. 0 when unknown.
duration
Length in seconds, with decimals.
rating
0 to 5.
play_count
How many times it was played.
format
Such as "FLAC" or "MP3".
path
Where the file is on this computer.

Listen

track_id
The song's id.
title, artist, album
As they were when it was played.
started_at
When it started, in seconds since 1970 (UTC).
seconds
How long it was heard.
qualified
true when it counts as a play: half the song or four minutes, whichever is shorter.

Limits and safety

  • Plugins start turned off. A new or changed plugin does nothing until someone turns it on.
  • Plugins run on their own thread. A slow plugin cannot freeze Needle's window or make the music skip.
  • Each call can do about 2 million steps. After that, Needle stops it and shows a message, so a loop that never ends cannot hang Needle.
  • Other limits: calls 48 deep, text up to 1 MB, lists up to 50,000 items, maps up to 10,000 keys. eval is not available.
  • An error in one plugin stays in that plugin. Needle shows it under the plugin's name in Settings, and the other plugins keep working.

Examples

Press Add example plugins in Settings to get these four. Open their folders to read or change them.

Now playing to a file

Keeps now-playing.txt up to date, for streaming software such as OBS. Needs "files".

fn on_track_start(track) {
    write_file("now-playing.txt", `${track.artist} — ${track.title}`);
}
fn on_pause() {
    write_file("now-playing.txt", "");
}

This week's favourites

A command that makes a playlist of your 25 most played songs of the last 7 days. Needs "library.read" and "library.write".

fn commands() {
    [ #{ id: "build", title: "Build “This week” playlist", scope: "global" } ]
}
fn run(command, ids) {
    let songs = library_search("played(7d) order by play_count desc limit 25");
    if songs.len() == 0 {
        notify("Nothing played in the last 7 days yet.");
        return;
    }
    save_playlist("This week", songs.map(|t| t.id));
    notify(`Made “This week” with ${songs.len()} songs.`);
}

Skip very short tracks

Skips intros and interludes under 30 seconds, and remembers a setting. Needs "playback".

fn on_track_start(track) {
    let limit = setting("seconds");
    if limit == () { limit = 30; }
    if track.duration > 0.0 && track.duration < limit {
        next_track();
    }
}
fn commands() {
    [ #{ id: "toggle", title: "Skip tracks under 60 seconds instead of 30", scope: "global" } ]
}
fn run(command, ids) {
    let now = setting("seconds");
    let next = if now == 60 { 30 } else { 60 };
    set_setting("seconds", next);
    notify(`Now skipping tracks under ${next} seconds.`);
}

When something goes wrong

The plugin is not in the list
Its folder must be directly inside the plugins folder and hold a file named exactly plugin.toml. Press Reload.
It shows an error under its name
Needle shows the first problem it found, such as a typing mistake in the script, a bad id, or a missing entry file. Fix it and press Reload.
“did not ask for permission”
Add the permission to plugin.toml, press Reload, and turn the plugin on again.
A command does not show
Check that the plugin is on, and that each item in commands() has an id and a title. "track" commands show only in the menu of selected songs.
Two plugins have the same id
Needle loads only the first one, in folder-name order. Give each plugin its own id.
