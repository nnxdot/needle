Teach Needle new tricks.

A plugin is a small script in its own folder. It can react to what you play, add commands to menus, add sound effects, and use your library, but only in the ways it asks for. Nothing runs until you turn it on.

Your first plugin

Plugins are written in Rhai, a small scripting language that looks like JavaScript or Rust. You need a text editor and nothing else.

  1. In Needle, open Settings, then Plugins, and press Open plugins folder.
  2. Make a new folder in it, for example hello.
  3. In that folder, make a file named plugin.toml: 
    id = "hello"
name = "Hello"
version = "1.0.0"
description = "Says the name of each song as it starts."
author = "you"
  4. Next to it, make a file named main.rhai: 
    fn on_track_start(track) {
    notify(`Now playing ${track.title} by ${track.artist}`);
}
  5. Back in Needle, press Reload. Your plugin shows in the list. Turn it on, then play a song.

Every time you change a file, press Reload to load it again. To see finished plugins, press Add example plugins. Needle then copies seven examples into the folder (see Examples).

plugin.toml

This file tells Needle what the plugin is and what it may do.

KeyNeededWhat it is
idYesA short name that never changes. Use only letters, digits, - and _. Needle keeps the plugin's on/off state and its settings under this name.
nameYesThe name people see.
versionNoYour version, such as "1.0.0".
descriptionNoOne or two sentences about what it does.
authorNoYour name.
entryNoThe script file. The default is "main.rhai". It must be inside the plugin folder.
permissionsNoA list of what the plugin may do. The default is none.
opensNoFile types the plugin opens when they are dropped on Needle's window, such as ["json", "lrc"]. It gets them through on_file_dropped(file). Theme files (.toml) always go to Needle's themes.

Permissions

Ask only for what you use. Needle shows the list before someone turns the plugin on. Turning it on allows everything on the list.

PermissionAllows
"library.read"Searching songs and reading listening history.
"library.write"Changing ratings and saving playlists.
"playback"Playing, pausing, skipping, and adding to the queue.
"network"Web requests.
"files"Reading and writing files inside the plugin's own folder.
"audio"Moving the sliders of its own effects, and turning them on or off. A plugin needs no permission just to offer effects.
"ask"Asking you to choose a file, or to type something. The plugin gets only the file you choose.

Events

Define any of these functions, and Needle calls them at the right time. You can leave out the ones you do not need.

FunctionCalled when
on_load()The plugin is turned on, and when Needle starts or reloads plugins.
on_track_start(track)A song starts. track is a song.
on_listen(listen)Needle records a listen in your history. listen is a listen.
on_file_dropped(file)Someone dropped a file of a type in opens on Needle's window. file is #{ name, extension, text }; files over 1 MB are refused. When several plugins open the same type, the first one that is turned on gets it.
on_pause()Playback pauses.
on_resume()Playback starts again after a pause.
effects()The plugin loads. Returns its sound effects.

Code outside functions runs once, when the plugin loads. Rhai functions cannot see variables made outside them, so to remember something between calls, use set_setting and setting.

Commands

A plugin can add commands that people choose. commands() returns a list of them. run(command, ids) is called when one is chosen.

fn commands() {
    [
        #{ id: "five", title: "Rate five stars", scope: "track" },
        #{ id: "tidy", title: "Tidy my queue", scope: "global" },
    ]
}

fn run(command, ids) {
    if command == "five" {
        for id in ids { set_rating(id, 5); }
        notify(`Rated ${ids.len()} songs.`);
    }
}
  • "track" commands show in the menu of selected songs, under Plugins. ids holds the selected songs' ids.
  • "global" commands show in the command palette. ids is empty.
  • A plugin can have at most 32 commands. Needle asks for the list when the plugin loads, so press Reload after you change it.

Sound effects

A plugin can add effects to Sound › Effects. There, people add them to their chain, put them in order, turn them on or off, and move their sliders. Effects play after the equalizer, on every song, and on other speakers too. They are skipped when exclusive output is on, so that each file plays bit for bit.

effects() returns a list of effects. Most effects are a chain of Needle's built-in blocks, so they need no DSP code at all:

fn effects() {
    [
        #{ id: "room", name: "Room", description: "Places the music in a room.",
           params: [
               #{ id: "size", name: "Size", min: 0.0, max: 1.0, value: 0.5, unit: "%" },
               #{ id: "mix", name: "Amount", min: 0.0, max: 0.6, value: 0.2, unit: "%" },
           ],
           blocks: [ #{ kind: "reverb", size: "$size", mix: "$mix", damping: 0.5 } ] },
    ]
}
KeyWhat it is
idA short name that never changes, with letters, digits, - and _. Needed.
nameThe name people see. Needed.
descriptionOne sentence about the sound.
paramsUp to 16 sliders. Each has an id, a name, min, max, and a starting value. It can also have a step, and a unit to show after the number, such as "dB", "ms", or "Hz". With "%", a value from 0 to 1 shows as 0–100%.
blocksUp to 16 blocks, played in order. Or use wasm for your own DSP code.

A block has a kind and its settings. A setting is a number, or "$id" to follow the slider with that id. Settings you leave out use the starting value, and every value is kept between the lowest and highest shown.

KindSettings (starting value)
"gain"db (0), from −60 to 24.
"filter"shape: "lowpass", "highpass", "bandpass", "notch", "peak", "lowshelf", or "highshelf". Needed, and not a slider. frequency in Hz (1000), q (0.707), gain in dB (0), for peak and shelves.
"compressor"threshold in dB (−18), ratio (4), attack in ms (10), release in ms (120), makeup in dB (0).
"limiter"ceiling in dB (−1), release in ms (80).
"delay"time in ms (350, up to 2000), feedback (0.35, up to 0.95), mix (0.3).
"reverb"size (0.6), damping (0.4), mix (0.25), width (1). All from 0 to 1.
"chorus"rate in Hz (0.8), depth in ms (3), mix (0.4).
"tremolo"rate in Hz (5), depth (0.5).
"saturate"drive in dB (6), mix (1). Soft, tape-like clipping.
"width"amount (1): 0 is mono, 1 is unchanged, 2 is extra wide.
"pan"position (0), from −1 (left) to 1 (right).

Blocks run as Needle's own code on the audio thread, never as script. A script with the "audio" permission can still change them while music plays, with set_effect and effect_on. For example, it can turn on a night-time effect after 11 PM.

DSP code

For a sound the blocks cannot make, write the DSP code yourself and give Needle a WebAssembly module. You can write it in Rust, C, C++, Zig, or AssemblyScript and build a .wasm file. For small effects, you can also write WebAssembly text (.wat) by hand, and Needle reads it as it is.

fn effects() {
    [ #{ id: "crush", name: "Bitcrusher", wasm: "crush.wasm",
         params: [ #{ id: "bits", name: "Bits", min: 2.0, max: 16.0, value: 8.0, step: 1.0 } ] } ]
}

The module works on blocks of interleaved 32-bit float samples, from −1 to 1. It must export:

memory
Its memory.
init(rate: i32, channels: i32, max_frames: i32) -> i32
Called once for each song. Returns the address in its memory of a buffer with room for max_frames × channels samples. max_frames is 512.
process(frames: i32)
Needle fills the buffer with frames frames and calls this. Change the samples in place. Needle then reads them back.

It can also export:

param(index: i32, value: f32)
A slider's value, by its place in params, counted from 0. Needle calls it after init for every slider, and again whenever one moves.
reset()
Called after a seek. Clear delay lines and other kept sound here.

Here is a whole effect in WebAssembly text. It halves the volume of stereo sound:

(module
  (memory (export "memory") 1)
  (func (export "init") (param i32 i32 i32) (result i32) (i32.const 1024))
  (func (export "process") (param $frames i32)
    (local $at i32) (local $end i32)
    (local.set $at (i32.const 1024))
    ;; 2 channels × 4 bytes a sample
    (local.set $end (i32.add (i32.const 1024) (i32.shl (local.get $frames) (i32.const 3))))
    (block $done (loop $next
      (br_if $done (i32.ge_u (local.get $at) (local.get $end)))
      (f32.store (local.get $at) (f32.mul (f32.load (local.get $at)) (f32.const 0.5)))
      (local.set $at (i32.add (local.get $at) (i32.const 4)))
      (br $next)))))

The Bitcrusher example plugin is a longer one, with three sliders and reset. Open its crush.wat to read it.

The sandbox

  • A module cannot import anything. It has no files, network, clock, or system calls. It gets samples, and it gives samples back.
  • Its memory can grow to 32 MB. The file can be up to 8 MB.
  • Each block has a work budget. A module that runs out, stops with an error, or cannot keep up with the music is stopped for the rest of the song. The music plays on without it, and Sound › Effects shows why.
  • Needle checks the module when the plugin loads. A module without init, process, or memory, or whose buffer does not fit its memory, shows an error in Settings and never plays.

Functions

These are the functions your script can call. A function that needs a permission fails with a clear message if the plugin did not ask for that permission.

Always allowed

notify(text)
Shows a short message in Needle, with your plugin's name in front.
log(text)
Writes a line to Needle's log file, with your plugin's id. Open it from Settings › Your data › Open log folder.
now()
The current time, in seconds since 1 January 1970 (UTC).
now_playing()
The song playing now, or () if none.
setting(key)
A value this plugin saved earlier, or () if there is none.
set_setting(key, value)
Saves a value for this plugin. It is kept when Needle closes. Each plugin has its own settings.
parse_json(text)
Turns JSON text into Rhai maps and arrays.

library.read

library_search(rule)
Songs that match a search or a rule, the same as the search box in Needle. For example: "rating >= 4 and year < 2000", or "played(7d) order by play_count desc limit 25". Gives at most 10,000 songs. An empty rule gives all songs.
recent_listens(count)
Your most recent listens, newest first, from 1 to 1,000.

library.write

set_rating(id, stars)
Sets a song's rating, from 0 (none) to 5.
save_playlist(name, ids)
Saves a playlist with these songs. If your plugin saves a playlist with the same name again, Needle updates it and does not make a second one.

playback

play(ids)
Plays these songs now.
play_next(ids)
Puts these songs next in the queue.
enqueue(ids)
Adds these songs to the end of the queue.
toggle_playback()
Pauses, or plays again.
next_track(), previous_track()
Skips forward or back.

audio

set_effect(effect, slider, value)
Moves a slider of one of this plugin's effects, in every place the effect is in the chain.
effect_on(effect, on)
Turns one of this plugin's effects on or off. Turning on an effect that is not in the chain adds it at the end.

ask

ask_text(title, prompt), ask_text(title, prompt, text)
Shows a box to type in, with a title, a question, and (optionally) text already in it. Gives what was typed, or () if the person cancelled.
pick_file(title, types)
Asks the person to choose a file, such as pick_file("Choose a VS Code theme", ["json"]) (an empty list allows any type). Gives #{ name, extension, text } for that one file, or () if they cancelled. Files over 1 MB are refused.

The plugin waits while the person answers (up to ten minutes), and so do the other plugins, so ask only when someone has just done something, such as running a command.

network

http_get(url)
Fetches a web address and gives its text.
http_post_json(url, value)
Sends value as JSON and gives the reply's text.

A request stops after 15 seconds. A reply is cut at 1 MB. A reply that is not a success fails with the server's status.

files

read_file(name)
Reads a text file in the plugin's folder.
write_file(name, text)
Writes a text file in the plugin's folder, and replaces what was there.

Names are inside the plugin's folder, such as "now-playing.txt" or "themes/dark.toml"; write_file makes the folder if needed. .. and full paths are refused, so a plugin cannot touch files outside its folder. To read a file from elsewhere, ask for it with pick_file, or list its type in opens.

Music sources

A source plugin brings songs from a server: its songs show in Needle next to your own files, stream when they play, and can be queued, cast, rated, scrobbled, and added to playlists. Needle comes with one for Navidrome and other Subsonic servers; press Set up at the top of Settings › Plugins, or read its main.rhai after Add example plugins.

A source needs the "network" permission, because Needle downloads the links it gives. Sources are for music you own, bought, or that is free to stream. Do not write one for services with copy protection or terms that forbid other players, such as Spotify, Apple Music, Tidal, or YouTube Music.

FunctionNeededWhat it does
source()YesReturns #{ name, fields }: the name people see, and the boxes of the sign-in form. Each field is #{ id, label, placeholder, secret }; typed text in a secret field is hidden.
signed_in()YesReturns true when the plugin has what it needs to reach the server.
sign_in(fields)YesGets a map of what was typed, by field id. Save it (the password with set_secret), check it with the server, and throw a message if it is wrong. Needle shows the message under the form.
sign_out()NoForget what sign_in saved. The source's songs stay in the library, marked missing, with their ratings and plays, until you sign in again.
songs(page)YesReturns one page of songs, from page 0, as a list of source songs. Needle asks for the next page until one is empty. A page of 250 songs is a good size.
stream(id)YesReturns an http:// or https:// link to the song's audio.
playing(id)NoA song from this source started.
played(id, started_at)NoA song from this source counts as played (half of it, or 4 minutes). started_at is in seconds since 1970.
rate(id, stars)NoA song from this source was rated in Needle, from 0 to 5.

Needle gets the whole list of songs when someone signs in, when Needle starts (at most every 30 minutes), and when they press Update now. A song the server no longer lists is marked missing, never deleted. Songs stream into a cache as they play; the last 2 GB played stay on the computer and play again without the network. Jumping ahead in a song that is still downloading asks the server for that part first, when the server allows it. The song after the next one downloads ahead of time. Keep on this computer (in a song's menu, or the pin on a server album's page) downloads songs to play without the network and never clears them. Tag editing, stems, Fix my library, and measuring for radio skip server songs; Save to my music in a song's menu downloads it into the first music folder as a normal file.

Lyrics

A plugin can find lyrics by defining lyrics(song). Needle asks it only when a song has no lyrics beside it or in its tags, LRCLIB has no timed ones, and online lookups are on in Settings. Plugins that find lyrics are asked in turn: the first timed lyrics win, and plain ones are kept in case nothing better turns up. Needle keeps what they find for a month, and a miss for a day.

song has only what is needed to look a song up: title, artist, album, album_artist, and duration in seconds. Return one of these, or nothing:

#{ synced: text }
Timed lyrics in LRC, such as [00:12.50]A line. A string on its own is read the same way.
#{ plain: text }
Lyrics without timing.
#{ instrumental: true }
The song has no words.
fn lyrics(song) {
    let query = url_encode(song.artist + " " + song.title);
    let found = parse_json(http_get(`https://lyrics.example.com/find?q=${query}`));
    if found.lrc == () { return (); }
    #{ synced: found.lrc }
}

Needle comes with NetEase lyrics, which looks on NetEase Cloud Music: it has timed lyrics for a great many songs, Asian music above all. It starts turned off; turn it on in Settings › Plugins, or press Also look on NetEase where a song has no lyrics.

Limits and safety

  • Plugins start turned off. A new or changed plugin does nothing until someone turns it on.
  • Plugins run on their own thread. A slow plugin cannot freeze Needle's window or make the music skip.
  • Each call can do about 2 million steps. After that, Needle stops it and shows a message, so a loop that never ends cannot hang Needle.
  • Other limits: calls 48 deep, text up to 1 MB, lists up to 50,000 items, maps up to 200,000 keys (counting everything inside them). eval is not available.
  • An error in one plugin stays in that plugin. Needle shows it under the plugin's name in Settings, and the other plugins keep working.

Examples

Press Add example plugins in Settings to get these eight. Open their folders to read or change them. Two add sound effects: Studio effects (Room, Echo, Night mode, and Old radio, made from blocks) and Bitcrusher (DSP code in WebAssembly text). Navidrome / Subsonic is a music source, and NetEase lyrics finds lyrics.

Needle updates these plugins by itself when a new version of Needle has a newer one, as long as you have not changed them. If you have, Settings shows Update, which keeps your changed files next to the new ones as .mine files, and Keep mine.

Settings lists these under Official, and plugins you add under Community. An official plugin whose files are exactly as Needle installed them has a check mark next to its author. Once you change it, it says changed by you instead.

Now playing to a file

Keeps now-playing.txt up to date, for streaming software such as OBS. Needs "files".

fn on_track_start(track) {
    write_file("now-playing.txt", `${track.artist} — ${track.title}`);
}
fn on_pause() {
    write_file("now-playing.txt", "");
}

This week's favourites

A command that makes a playlist of your 25 most played songs of the last 7 days. Needs "library.read" and "library.write".

fn commands() {
    [ #{ id: "build", title: "Build “This week” playlist", scope: "global" } ]
}
fn run(command, ids) {
    let songs = library_search("played(7d) order by play_count desc limit 25");
    if songs.len() == 0 {
        notify("Nothing played in the last 7 days yet.");
        return;
    }
    save_playlist("This week", songs.map(|t| t.id));
    notify(`Made “This week” with ${songs.len()} songs.`);
}

Skip very short tracks

Skips intros and interludes under 30 seconds, and remembers a setting. Needs "playback".

fn on_track_start(track) {
    let limit = setting("seconds");
    if limit == () { limit = 30; }
    if track.duration > 0.0 && track.duration < limit {
        next_track();
    }
}
fn commands() {
    [ #{ id: "toggle", title: "Skip tracks under 60 seconds instead of 30", scope: "global" } ]
}
fn run(command, ids) {
    let now = setting("seconds");
    let next = if now == 60 { 30 } else { 60 };
    set_setting("seconds", next);
    notify(`Now skipping tracks under ${next} seconds.`);
}

When something goes wrong

The plugin is not in the list
Its folder must be directly inside the plugins folder and hold a file named exactly plugin.toml. Press Reload.
It shows an error under its name
Needle shows the first problem it found, such as a typing mistake in the script, a bad id, or a missing entry file. Fix it and press Reload.
“did not ask for permission”
Add the permission to plugin.toml, press Reload, and turn the plugin on again.
An effect does not show in Sound
Check that the plugin is on and has no error in Settings. Effects of a plugin that is off stay in the chain, marked as not available, until it is on again.
A command does not show
Check that the plugin is on, and that each item in commands() has an id and a title. "track" commands show only in the menu of selected songs.
Two plugins have the same id
Needle loads only the first one, in folder-name order. Give each plugin its own id.
